# DESIGN.md: Project Design System Specification

> **Notice:** This document defines the visual tokens, typography, colors, and component rules for this repository. All UI components generated by AI agents MUST adhere strictly to these tokens.

---

## 1. Palette & Color Tokens

### Base Palette (Dark Theme Default)
- `background`: `hsl(240 10% 3.9%)` (#09090b)
- `foreground`: `hsl(0 0% 98%)` (#fafafa)
- `card`: `hsl(240 10% 6.5%)` (#121215)
- `card-foreground`: `hsl(0 0% 98%)` (#fafafa)
- `popover`: `hsl(240 10% 8%)` (#16161a)
- `popover-foreground`: `hsl(0 0% 98%)` (#fafafa)

### Brand Accent Token
- `primary`: `hsl(142.1 76.2% 36.3%)` (Crisp Emerald #10b981)
- `primary-foreground`: `hsl(355.7 100% 99%)`
- `muted`: `hsl(240 3.7% 15.9%)`
- `muted-foreground`: `hsl(240 5% 64.9%)`
- `border`: `hsl(240 3.7% 15.9% / 0.6)`

---

## 2. Typography Rules

- **Display & Headings:** Geist Sans / Inter (`font-sans font-semibold tracking-tight`)
- **Body:** Geist Sans / Inter (`font-sans text-sm leading-relaxed`)
- **Data & Numbers:** Geist Mono / JetBrains Mono (`font-mono text-xs text-muted-foreground`)

```markdown
Title 1: text-2xl font-bold tracking-tight text-foreground
Title 2: text-lg font-semibold tracking-tight text-foreground
Section Label: text-xs font-medium uppercase tracking-wider text-muted-foreground
Body Copy: text-sm text-muted-foreground
```

---

## 3. Elevation & Radius Specs

- `radius-sm`: `0.25rem` (4px, badges/tags)
- `radius-md`: `0.375rem` (6px, buttons, inputs, dropdown items)
- `radius-lg`: `0.5rem` (8px, small cards, popovers)
- `radius-xl`: `0.75rem` (12px, main container cards, dialogs)

---

## 4. Layout Micro-Grid Rules

- Standard layout padding: `p-4` (mobile), `p-6` (desktop)
- Component gap budget: `gap-3` (8px-12px) for tight controls, `gap-6` (24px) between grid panels
- Every component MUST include explicit dark/light mode class variants (`dark:bg-card bg-white`).
